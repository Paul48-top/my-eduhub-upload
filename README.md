# EduHub

A simple school management system to manage assignments for students, manage teachers, and classes.

I made this to practice connecting a Java backend with a React frontend.

**Tech stack:**
- Backend: Java Spring Boot, MySQL
- Frontend: React, Vite
- API: REST

**Features:**
- Login with roles (Admin, Teacher, Student)
- Create classes and enroll students
- Dashboard for each role

**Project structure:**
appeduhub-api/ - backend code
eduhub-frontend/ - frontend code

**How to run:**
1. Backend: 
   cd appeduhub-api
   mvn spring-boot:run
2. Frontend:
   cd eduhub-frontend
   npm install
   npm run dev

**Status:** Working locally, still improving.
